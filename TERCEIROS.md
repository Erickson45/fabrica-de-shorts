# Componentes de terceiros

A Fábrica de Shorts **não inclui** estes componentes no pacote. O `instalar.bat` baixa cada um direto da fonte oficial, e cada um segue a sua própria licença.

| Componente | Para que serve | Licença |
|---|---|---|
| [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) e [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx) | narração | Apache 2.0 / MIT |
| [Ollama](https://ollama.com) | roda a IA dos roteiros | MIT |
| [Gemma 3](https://ai.google.dev/gemma/terms) | IA dos roteiros (opção 1) | Termos de Uso do Gemma (Google) |
| [Qwen 2.5](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct) | IA dos roteiros (opção 2) | Apache 2.0 |
| [FFmpeg](https://ffmpeg.org) (build Gyan) | montagem do vídeo | GPL |
| [Python](https://www.python.org) | linguagem do programa | PSF |
| Flask, NumPy, Pillow, SoundFile, Requests, ONNX Runtime, bibliotecas Google API | bibliotecas | BSD / MIT / Apache 2.0 |

## Conteúdo

- **Vídeos de fundo — [Pixabay](https://pixabay.com/service/license-summary/):** uso livre, inclusive comercial, sem atribuição obrigatória. Não revenda os clipes isolados.
- **Perguntas importadas — [Open Trivia Database](https://opentdb.com):** licença CC BY-SA 4.0. O programa coloca o crédito na descrição dos vídeos que usam essas perguntas. Não remova.
- **Fatos e perguntas escritos à mão** (`bancos/`): fazem parte do projeto e seguem a licença MIT (arquivo `LICENSE`).
- **Trilha e efeitos sonoros:** gerados pelo próprio programa na hora. Não há música de terceiros.
